# Agentic AI Resume Screener & Career Coach
Built for Hiring Team - 4 Agent System

**Live Demo:** Coming soon on Hugging Face
**Tech:** Python, FastAPI, Gemini, Qdrant, LangGraph, Docker, RAG

Features:
- Parser Agent: Extracts skills from PDF resumes using Gemini
- Evaluator Agent: Scores against JD
- Q&A Agent: RAG with Qdrant for interview prep
- Feedback Agent: Suggests improvements
